## Kør appen

```
npm install
npx expo start
```

## AI-råd (valgfrit)

Uden API-nøgle viser appen beregnede råd. Sådan slås AI-rådene til:

1. Opret en gratis nøgle på console.groq.com.
2. Kopiér `.env.example` til `.env.local`, og indsæt nøglen i `EXPO_PUBLIC_GROQ_API_KEY=`.
3. Start med `npx expo start -c`.
